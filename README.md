##  Sobre o Projeto

Este projeto foi desenvolvido para transformar dados brutos de emplacamentos de veículos em informações estratégicas para análise do mercado automotivo brasileiro.

A solução foi construída utilizando **Power BI**, com foco em Business Intelligence, permitindo acompanhar a evolução das vendas, identificar tendências de mercado e analisar como fatores econômicos, como a **Taxa Selic**, influenciam o comportamento dos consumidores.

Além da construção do dashboard, o projeto envolveu todo o processo de preparação dos dados, desde a consolidação das bases até a criação de indicadores estratégicos.

---

#  Objetivo

Desenvolver um dashboard executivo capaz de responder perguntas importantes para o negócio, como:

- Como o mercado automotivo evoluiu entre 2020 e 2025?
- O aumento da Taxa Selic impactou o faturamento?
- Quais montadoras dominaram o mercado?
- Quais categorias de veículos cresceram mais?
- Quais modelos geraram maior receita?
- Qual foi o comportamento das vendas ao longo dos anos?

#  Processo de Desenvolvimento

##  Coleta dos Dados

Os dados foram obtidos em arquivos CSV contendo informações de emplacamentos de veículos entre 2020 e 2025.

---

##  ETL

Durante a preparação dos dados foram realizadas etapas de:

- Importação dos arquivos
- Padronização das tabelas
- Remoção de inconsistências
- Tratamento de valores nulos
- Ajuste dos tipos de dados
- Consolidação das bases anuais

Todo o processo foi realizado utilizando o **Power Query**.

---

##  Modelagem de Dados

Após o tratamento foi criada uma estrutura de dados otimizada para consultas analíticas.

Essa modelagem permitiu melhorar o desempenho do dashboard e facilitar a criação dos indicadores.

---

##  Criação das Medidas

Entre elas:

- Faturamento Médio
- Ticket Médio
- Total de Veículos
- Média da Selic
- Participação de Mercado
- Receita por Modelo

#  Principais Insights

A análise dos dados permitiu identificar diversos comportamentos relevantes do mercado automotivo.

Entre eles:

- Crescimento do faturamento mesmo em períodos de alta da Taxa Selic.
- SUVs e Picapes ganharam participação de mercado durante o período analisado.
- Alguns modelos permaneceram líderes de vendas em todos os anos.
- O comportamento do consumidor mudou conforme o cenário econômico.
- O dashboard permite comparar rapidamente marcas, categorias e modelos utilizando filtros dinâmicos.
